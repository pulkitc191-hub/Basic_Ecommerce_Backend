# E-Commerce Backend

A backend REST API for an e-commerce application built using Spring Boot.

## Tech Stack

- Java
- Spring Boot
- Spring Data JPA
- Hibernate
- PostgreSQL
- Docker
- Maven
- Lombok

## Features

- Category CRUD operations
- Product CRUD operations
- Product-Category relationships
- DTO-based API architecture
- Entity-DTO mapping
- Request validation
- Global exception handling
- Pagination
- RESTful API design

## Architecture

Controller → DTO → Service → Entity → Repository → PostgreSQL

This project is being developed step-by-step to understand how a real-world Spring Boot backend is structured and built.
